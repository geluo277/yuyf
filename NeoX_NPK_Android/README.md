# NeoX NPK 解包器（Android）

基于 NeteaseUnpackTools 的 NPK 索引解析逻辑移植。

## 手机直接编译 APK

1. 手机浏览器打开 GitHub，创建一个新的 Repository。
2. 将本工程全部文件上传到仓库。
3. 打开仓库的 Actions。
4. 选择 `Build Android APK`。
5. 点击 `Run workflow`。
6. 等待构建完成。
7. 打开完成的 workflow，进入 Artifacts。
8. 下载 `NeoX-NPK-Unpacker-debug`。
9. 解压后得到 `app-debug.apk`，在 Android 手机上安装。

如果 Actions 未启用，在仓库 Settings → Actions 中允许 GitHub Actions。
